The Language

What is Forge?

  • A statically-typed language that compiles to clean JavaScript
  • Built on Ohm.js — a PEG grammar framework
  • Explicit types at function boundaries, inferred inside function bodies
  • Intentional keyword choices — code reads like intent, not mechanics
  • No runtime library needed — output runs anywhere JavaScript runs

Forge was built by asking: what should code say? Every keyword is chosen to communicate intent — not just syntax.

Design Goals

Why These Choices?

Goals
  • Returns communicate whether a value is given back
  • Loop forms communicate what kind of iteration it is
  • Bit manipulation is a first-class operation, not an afterthought
  • Types prevent surprises at function boundaries
Tradeoffs Made
  • Verbose keywords over terse symbols where meaning matters
  • No classes in v0.1 — focused scope beats feature bloat
  • Static analysis errors are loud — fail early, never at runtime
  • No Forge runtime — simpler deployment, pure JS out

Syntax

Forge in Action

// Bit population count — counts set bits in an integer
func countBits(x: inum): inum {
  let count = 0;
  let n = x;
  whenis (n != 0) {
    count += n & 1;          // symbolic bitand
    n = n shiftr 1;
  }
  deliver count;             // valued return
}

let flags = 0;
flags{0} = TT;              // set bit 0
flags{2} = TT;              // set bit 2
flags{2} = FF;              // clear bit 2

Conclusion

What We Learned

  • Every keyword is a design decision — and every decision has a cost
  • Static analysis is most valuable when it fails loudly and early
  • An optimizer that understands your type system can eliminate entire branches
  • Grammar ambiguity is the hardest bug to debug
